A document database that heals itself.

Firestore-simple to use — collections, documents, one API key, no schema, no ops. Underneath, every read is routed by a real pheromone-based ant colony algorithm across replicated shards: it learns which replica is fastest, and reroutes around failures on its own, with no coordinator ever recomputing a plan.

Quickstart

One key, one script. No dashboard sign-up flow.

curl -X POST http://localhost:4280/v1/keys
# {"apiKey":"ant_...")}

curl -X POST http://localhost:4280/v1/db/users \
  -H "Authorization: Bearer ant_..." \
  -H "Content-Type: application/json" \
  -d '{"name":"Ada","balance":100}'
# {"id":"...","name":"Ada","balance":100}

Or from JS (Node or the browser) with the bundled SDK:

import { AntSQL } from './sdk/antsql-client.js';

const apiKey = await AntSQL.createKey('http://localhost:4280');
const db = new AntSQL({ apiKey, baseUrl: 'http://localhost:4280' });

const ref  = await db.collection('users').add({ name: 'Ada' });
const snap = await db.collection('users').doc(ref.id).get();
console.log(snap.data()); // { name: 'Ada' }

Schemaless

Documents are plain JSON. No migrations, no column types.

Self-healing reads

Every read tries the ant colony's current favorite replica first, and transparently falls back if it's down.

One key = one namespace

Every API key is its own isolated database. No cross-tenant collisions.

Durable

Every write is appended to a write-ahead log per replica before it's acknowledged.

API reference

POST   /v1/keys                        create an API key (no auth)

GET    /v1/db/:collection              list documents
POST   /v1/db/:collection              create with a generated id
GET    /v1/db/:collection/:id          read one document
PUT    /v1/db/:collection/:id          create or replace
PATCH  /v1/db/:collection/:id          merge fields
DELETE /v1/db/:collection/:id          delete

GET    /v1/_colony/stats               shard/replica health + pheromone
POST   /v1/_colony/replicas/:id/fail   simulate a replica outage
POST   /v1/_colony/replicas/:id/heal   bring it back (auto-resyncs)

All /v1/db and /v1/_colony routes require: Authorization: Bearer <apiKey>
